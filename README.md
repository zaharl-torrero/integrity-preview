# Интегрити — концепция нового сайта

Редизайн https://integrity.ru/ в подарок команде — из любви к слову integrity. Статический сайт, всё для публикации лежит в `dist/`, сборка не нужна.

## Просмотр

`Запустить сайт.cmd` или `python -m http.server 8770 --bind 127.0.0.1 --directory dist`, затем http://127.0.0.1:8770/

Опубликованная версия: https://zaharl-torrero.github.io/integrity-preview/

Репозиторий: https://github.com/zaharl-torrero/integrity-preview . GitHub Pages публикует `dist/` через workflow при push в main.

## Что изменилось

- Фирменный бирюзовый `#27bebe` сохранён; основа — глубокий графит и тёплая бумага, шрифты Onest и IBM Plex Mono.
- Hero: сетка из 25 плиток, которые собираются в целое (integritas — «целостность»); на курсор плитки расходятся, по клику разлетаются и собираются снова. Бегущая строка стека.
- Продукты SP-PublicProjects и ИнтелДок — переключатель вкладок (работает со стрелками), скриншоты в окне, процессы, эффект от внедрения, ссылки на документацию на действующем сайте.
- Услуги — раскрывающийся список, открыт один пункт.
- Компетенции — при наведении на технологию подсвечиваются все направления, где она встречается.
- Проекты — карточки с окном просмотра, листание стрелками.
- Форма с темой обращения: «Задать вопрос» и «Пригласить разработчиков» сразу выбирают тему.
- Плавающее меню: прячется при прокрутке вниз, темнеет над тёмными секциями, подсвечивает текущий раздел; мобильное меню.

## Содержание и ограничения

Все тексты, фото продуктов и проектов, реквизиты и контакты взяты с действующего сайта 25.11.2026, ничего не добавлено, кроме расшифровки слова integritas. Шрифты и картинки хранятся локально, внешних скриптов и аналитики нет.

Форма не отправляет данные на сервер: открывает письмо на info@integrity.ru с заполненным текстом или копирует текст. Английская версия и карта Яндекса не перенесены: в футере ссылка на действующую `/en/`, адрес открывает Яндекс Карты.

Учитывается системная настройка уменьшения движения.

## Проверка

`node tests/check.mjs` при запущенном сервере (для опубликованной версии: `SITE_URL=https://zaharl-torrero.github.io/integrity-preview/`). Использует Playwright из проекта «Порядок» и локальный Chromium. Ширины 360–1920 px, переполнение, загрузка картинок, вкладки продуктов, список услуг, подсветка стека, окно проектов, выбор темы и проверка полей формы, копирование текста, мобильное меню, появление блоков, ошибки JavaScript и чтение без JavaScript. Скриншоты — в игнорируемой `tmp/check/`.
